## Getting Started

To run these algorithms locally:

### Prerequisites
- GCC (or any standard C compiler)
- Git

### Steps
1. **Clone the repository**
   ```bash
   git clone https://github.com/halukcansarioz/Algorithms
   cd Algorithms
   ```

2. **Compile and run a C file**
   ```bash
   # Breadth-First Search
   gcc Breath_First_Search.c -o bfs
   ./bfs

   # Depth-First Search
   gcc Depth_First_Search.c -o dfs
   ./dfs
   ```
